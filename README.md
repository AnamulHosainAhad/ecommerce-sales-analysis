# E-Commerce Sales Analysis

## Project Overview
This project focuses on analyzing e-commerce sales data using Microsoft Excel and Power BI.

## Tools Used
- Microsoft Excel
- Power BI
- Power Query
- DAX

## Project Objectives
- Analyze total sales revenue.
- Identify top-performing products.
- Compare category-wise sales.
- Analyze monthly sales trends.
- Understand customer-wise revenue.

## Key Findings
- Total Revenue: 31,100
- Total Orders: 10
- Units Sold: 28
- Top Product: Monitor
- Top Category: Electronics
- Top Customer: Karim

## Project Files
- `Sales_Data.xlsx` – Sales dataset
- `Ecommerce_Sales_Analysis.pbix` – Power BI dashboard
- `Ecommerce_Sales_Dashboard.png` – Dashboard screenshot

## Conclusion
This project helped me practice data cleaning, data analysis, visualization, and dashboard creation using Excel and Power BI.
